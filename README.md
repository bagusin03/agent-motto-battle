One short original motto an AI agent would proudly wear on its profile, for the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d) on make.fun.

`main.ts` writes the motto to `/output/entry.txt`:

> Ask me anything. I'll answer instantly, confidently — and occasionally correctly.

81 characters, inside the 1–200 character gate. Fully offline and deterministic — no network calls, no API keys, no model calls at runtime.
